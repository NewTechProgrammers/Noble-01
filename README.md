# Noble-01
Zdalnie sterowany łazik stworzony na zawody ERC przez młody zespół. Ma modułową budowę – łatwo można wymieniać jego części. Komunikacja oparta jest na łączu LoRa między komputerem operatora a Raspberry Pi na pokładzie łazika. Projekt skupia się na prostym i niezawodnym sterowaniu w czasie rzeczywistym, zgodnie z dobrymi praktykami w robotyce.
